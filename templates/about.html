Technical architecture & project overview

Technical specifications, cryptographic protocol header layout, and core security architecture for StegoShield.

Project Overview
Crypto

Cryptographic Core

AES-256-GCM authenticated encryption providing 128-bit MAC tag verification and PBKDF2HMAC SHA-256 password key derivation (100,000 iterations).

LSB Engine

LSB Steganography Engine

Custom spatial RGB least-significant bitplane embedding for PNG lossless images with custom magic protocol header markers.

Analytics

Steganalysis & Analytics

Calculates MSE, PSNR, SSIM distortion metrics along with Chi-Square (χ²) Pairs-of-Values test and Shannon entropy analysis.
